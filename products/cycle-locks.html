Frequently Asked Questions

Which lock is best for my cycle?
For daily city use, cable or chain locks work great. For expensive cycles, we recommend U-locks or alarm locks for extra security.
Do alarm locks really work?
Yes! Alarm locks trigger a 100dB+ sound if anyone tries to move the cycle. This scares off thieves immediately.
Are these locks waterproof?
All our locks are rust-proof and weather-resistant. Safe to use in monsoon season.
What if I lose my lock keys?
For key locks, we can arrange replacements with the manufacturer. For combination locks, just reset the code using the master key.
